# SLIDE Website

Static website for SLIDE.

## Local Preview

```sh
make site
```

Then open:

```text
http://localhost:8080
```

To view from another device on the same Wi-Fi:

```sh
make ip
```

Then open:

```text
http://YOUR-MAC-IP:8080
```

## Domain

Canonical domain:

```text
slidecolorsound.com
```
